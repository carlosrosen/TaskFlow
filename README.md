# 📋 TaskFlow

O TaskFlow é uma aplicação web desenvolvida para gerenciamento de tarefas pessoais, permitindo que usuários organizem suas atividades de forma simples e organizada.
O sistema conta com autenticação de usuários e funcionalidades completas de CRUD (Create, Read, Update, Delete) para tarefas.
Este projeto foi desenvolvido como trabalho da disciplina de Desenvolvimento Web da faculdade, com foco na aplicação prática dos conceitos aprendidos em sala.

## Funcionalidades

- Sistema de login e cadastro de usuário
- Cadastro de tarefas
- Listagem de tarefas
- Edição de tarefas
- Exclusão de tarefas
- Isolamento de dados por usuário
- Armazenamento local (localStorage)

## Tecnologias utilizadas:

- HTML5
- CSS3
- Javascript

# Pré-requisito:

Antes de executar o projeto, é necessário ter instalado:

- Node.js
- npm

## Instalação e execução:

1. Clone o repositório:

```bash
git clone https://github.com/carlosrosen/TaskFlow.git
```

2. Acesse a pasta do projeto:

```bash
cd TaskFlow
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie a aplicação:

```bash
npm run dev
```
